# Independent audit of the 9.8.5 build

This is an audit of the build branch of pull request 117 against the plan `docs/plans/two-approval-run.md`. It was
made on 2026-11-21 by agents that did not build the branch. It read commit `dc108ee` and tested its high and medium
findings again on commit `5fe91a6`. The build was still in its last package then, so this file is a list of things
to verify on the newest commit, not a verdict on the finished branch.

## How it was made

- Eleven auditors, one for each part of the plan. Each read the code, ran it, and broke a behaviour on purpose to
  see whether its check notices.
- Every gap an auditor reported went to a second agent whose job was to refute it. 104 gaps were reported, 25 were
  refuted, and 79 stood.
- The high and medium gaps that stood were then tested again on `5fe91a6`, because the build fixed many things in
  its own final review meanwhile. Low gaps were not tested again.
- No model was called. Every run used the scripted agents of `scripts/e2e`.

## What to do with it

For each finding under "Still open": reproduce it on your newest commit first. If it reproduces, write the check
that fails, then the fix. If the plan or a recorded decision allows it, say where. If it is a decision for the
owner, put it in the list for the owner. Never make a check pass by loosening it.
