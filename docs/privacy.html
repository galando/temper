Temper plugin for Claude Code · Last updated: October 6, 2026

Summary: Temper collects no data. It has no servers, no telemetry, no analytics, and makes no network calls.

What Temper is

Temper is an open-source plugin for Claude Code, distributed as Markdown instruction files and shell scripts. It runs entirely inside your local Claude Code session. The full source is public at github.com/galando/temper.

Data collection

  • No data is collected or transmitted. Temper contains no telemetry, analytics, crash reporting, or phone-home mechanism of any kind.
  • No accounts. Temper needs no account of any kind.
  • No network calls. Temper itself never contacts any server. The only network activity involved in using it is the plugin download/update from GitHub, performed by Claude Code's plugin manager.

Where your data lives

Everything Temper produces — plans, scenarios, review reports, metrics, learning state — is written to files inside your own project directory (.temper/, .claude/). These files stay on your machine and under your version control. Deleting them removes all Temper state.

The optional mod (Claude Code 2.1.287 or later) reads only these same project files, plus .git/HEAD, and writes no file. It makes no network calls and sends no telemetry. In the plugin store on your machine it keeps the decisions it recorded (with a hash of each), the run report, your first-run choice, and the best score of the optional game. When you change its mode or enforcement, on your command (a /temper:temper word you type, or your answer to its mode question), it reads Claude Code's /config list to find its own two rows and changes only its two settings, temper.uiMode and temper.enforcement, through Claude Code, which keeps them in your user settings. It changes no other setting.

Apart from that plugin store and those two settings, Temper reads one place outside your project: its own global pack folder, ~/.claude/packs, if you made one. It opens no other file in your home Claude Code folder: no settings file, keys, logins, plugin lists, skills or commands. The guardrails pack never reads or writes the settings in your home folder; it changes only your project's own settings files, after you confirm.

When something leaves your machine

Two optional features send text out, and only when you choose them:

  • Share HTML review. When you pick it at the plan gate and confirm, Claude Code's Artifact tool publishes the plan review as a private Claude artifact, and you decide who can open it. Without the Artifact tool, Temper offers the local review instead.
  • OCR, off by default. If you turn it on with tools.ocr.mode and the ocr tool is on your machine, /temper:review uses it, and ocr sends the diff to the model provider you set up for it.

Claude Code

Temper runs as instructions executed by Claude Code. Your interactions with Claude Code itself are governed by Anthropic's Privacy Policy, which is independent of Temper.
